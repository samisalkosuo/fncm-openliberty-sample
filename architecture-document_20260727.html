FileNet OpenLiberty — Architecture Document

IBM FileNet Content Platform Engine · CP4BA · OpenLiberty 24 · Jakarta EE 10 · MicroProfile 7.1

1. Overview

filenet-openliberty is a Jakarta EE 10 web application deployed on IBM OpenLiberty that acts as a secure middleware layer between a browser-based single-page application (SPA) and an IBM FileNet Content Platform Engine (CPE) instance running inside IBM Cloud Pak for Business Automation (CP4BA).

The application exposes a REST API (/api/*) and serves a single HTML page (index.html). It handles the two-step CP4BA token exchange (IAM → Zen), maintains a server-side token cache, proxies GraphQL queries to the CP4BA Content Services GraphQL endpoint, and issues direct FileNet Java API (JACE) calls to the Content Engine WSI endpoint.

5. Authentication & Token Flow

The application implements the two-step CP4BA token exchange used by all IBM CP4BA clients:

After login, the browser stores the Zen token in sessionStorage and sends it as Authorization: Bearer <token> on every subsequent API call. The server-side BearerTokenFilter validates the token against the in-memory TokenCache and populates the request-scoped TokenContext before any JAX-RS resource method is invoked.

7. Security Layer

BearerTokenFilter @Provider

A JAX-RS ContainerRequestFilter registered globally via the @Provider annotation. It intercepts every /api/* request before the resource method is called. The only exemption is any path containing /auth/ (the public login endpoint).

  • Reads the Authorization: Bearer <token> header.
  • Calls TokenCache.getUsername(token) — returns null if the token is unknown.
  • On failure: aborts the request with HTTP 401 and a JSON error body (no WWW-Authenticate header to suppress browser login dialogs).
  • On success: calls TokenContext.set(zenToken, iamToken, username) so resources can inject TokenContext.

TokenCache @ApplicationScoped

An in-memory ConcurrentHashMap mapping Zen tokens to a record of (username, iamToken). It is populated on login and is valid for the lifetime of the server process.

Note: The cache does not survive server restarts. For multi-instance or HA deployments it must be replaced with a distributed cache (e.g. Redis or Infinispan).

TokenContext @RequestScoped

A lightweight per-request CDI bean that carries the validated Zen token, the optional IAM token, and the username. Injected directly into resource classes via @Inject TokenContext tokenContext.

8. FileNet JACE API Layer

BaseFileNetApp<T> — Abstract Lifecycle Base

All JACE-backed service classes extend BaseFileNetApp<T>. The run() method executes the full JACE lifecycle:

  1. loadConfiguration — reads filenet-cli.properties from the classpath, then overrides from environment variables.
  2. configureTrustAllSSL — installs a trust-all SSLContext (development only).
  3. authenticate — creates OpenTokenCredentials(username, oauthToken, null) using the Zen token passed in from the REST layer.
  4. doAs block — all CE API calls run inside credentials.doAs() so the token is attached to every WSI HTTP request.
  5. connect / fetchDomainAndObjectStore — Factory.Connection.getConnection(url), then Factory.Domain.fetchInstance and Factory.ObjectStore.fetchInstance.
  6. doWork(objectStore, args) — abstract method implemented by each concrete service.
  7. disconnect — cleanup in finally block.

ConnectionTest

Connects to CPE, retrieves the domain name and object store display name, and returns a plain-text connection summary (Status, Domain, Object Store, User).

ListFolders

Executes the SQL query SELECT TOP 100 FolderName, PathName, Id, DateCreated, Creator FROM Folder ORDER BY DateCreated DESC against the configured object store using SearchSQL + SearchScope. Results are returned as a formatted text block.

9. GraphQL Proxy

The browser sends GraphQL queries to POST /api/graphql (same origin — no CORS). GraphQLProxyResource delegates to the GraphQLClient CDI bean, which:

  • Generates a random UUID as an ECM-CS-XSRF-Token per request.
  • Sets both the request header and the Cookie header (required by Content Services GraphQL).
  • Sets Authorization: Bearer <zenToken>.
  • POSTs to the URL configured in external.api.base.url (MicroProfile Config).
  • Returns the upstream response body verbatim, preserving the HTTP status code.

The raw GraphQL response (including any errors array) is returned directly to the browser. The SPA formats and displays it in the GraphQL Query card.

10. Frontend Single-Page Application

The entire UI lives in a single file: src/main/webapp/index.html. It is served by the Liberty servlet container at the context root /.

View Routing

Two CSS views exist: #view-login and #view-app. The active view is toggled by adding/removing the .active class. On page load the app checks sessionStorage for a saved session and skips straight to the app view if one exists.

Session Management

After a successful login, the session object (appToken, accessToken, username) is stored in sessionStorage and cleared on logout. All secured API calls attach Authorization: Bearer <appToken>.

13. Build & Container

Maven Build

The two FileNet JARs (Jace.jar, p8cel10n.jar) are not in Maven Central. They must be installed into the local Maven repository before running mvn package: 

mvn install:install-file -Dfile=lib/Jace.jar \
    -DgroupId=com.ibm.filenet -DartifactId=Jace -Dversion=5.5 -Dpackaging=jar

mvn install:install-file -Dfile=lib/p8cel10n.jar \
    -DgroupId=com.ibm.filenet -DartifactId=p8cel10n -Dversion=5.5 -Dpackaging=jar

mvn package -DskipTests

Output: target/app.war (final artifact name configured in pom.xml).

15. Known Limitations & Extension Points

  • In-memory token cache — does not survive server restarts; single-node only.
  • No token expiry enforcement — tokens remain in the cache indefinitely until the server restarts or the user logs out.
  • Trust-all TLS — both AuthService and BaseFileNetApp disable certificate verification globally when the flag is false. Must be hardened for production.
  • DocumentResource is a stub — it always returns an empty document list. The commented-out code illustrates the intended pattern.
  • FileNet credentials in properties file — filenet-cli.properties contains a plaintext password. Use environment variable injection in production.
  • JACE services instantiated per-request — ConnectionTest and ListFolders are new-ed inside the resource method; they are not CDI beans, which means a new JACE connection is opened and closed per request.
